🚗 MyCar – Second-Hand Car Selling Platform

MyCar is a web-based platform designed for buying and selling second-hand cars. The application allows users to browse available cars, view detailed information, and connect with sellers easily through a simple and user-friendly interface.

🌐 Live Demo

🔗 https://mycars-dwqb.vercel.app/

✨ Features

🚘 Browse second-hand cars

📄 View car details (model, price, condition)

📞 Easy contact for seller inquiries

📱 Fully responsive design

⚡ Fast and lightweight frontend

🛠️ Tech Stack

Frontend: Next js

Deployment: Vercel

Styling: Tailwind css
Auth: Google OAuth2

▶️ Run Locally
git clone [https://github.com/your-username/mycar.git](https://github.com/ritiksharma1089/Mycars.git)
cd mycar
npm install
npm start
